MUAY THAI TRAINING — VERSÃO 2 (TREINOS FLEXÍVEIS)

NOVIDADES:
- Agenda semanal personalizável: escolha vários treinos para cada dia.
- Biblioteca de treinos com criação de fichas personalizadas.
- Adição de exercícios às fichas criadas pelo usuário.
- Treino livre para registrar uma sessão sem ficha programada.
- Fichas originais A, B, C e D continuam disponíveis.
- Diário de cargas, histórico e check-ins mantidos no armazenamento local.
- Cronômetro e links de busca de vídeos demonstrativos.

DADOS:
- Esta versão mantém a chave local mtt_v1 para preservar os registros da versão anterior.
- Fichas e agenda personalizadas ficam salvas no mesmo aparelho/navegador.
- Não há sincronização automática entre dispositivos; faça backup antes de limpar dados do navegador.
- As fichas originais não são editáveis; crie fichas personalizadas para adaptar os exercícios.
- Excluir uma ficha personalizada remove-a da agenda, mas não apaga os registros históricos de cargas.

INSTALAÇÃO:
1. Publique os arquivos na raiz do GitHub Pages.
2. Abra o endereço HTTPS no Chrome do Android.
3. Menu ⋮ > Instalar app ou Adicionar à tela inicial.

OBSERVAÇÃO:
Os vídeos abrem buscas no YouTube; não são vídeos incorporados. Ajuste os exercícios com seu professor/profissional de educação física.
